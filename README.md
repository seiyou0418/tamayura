TAMAYURA is an original colour-matching arena game for the browser: you are a spirit flame guarding a shrine courtyard at night, and Hollow Shards in three colours — Ember, Tide and Bloom — are coming for the fire. Your bolts only shatter a shard that matches your flame's colour (Q / E, the mouse wheel or right-click shifts it); wrong colours knock a shard back and charge your Nova, which Space unleashes in a courtyard-wide burst when the meter is gold. Survive escalating waves, chain combos for score multipliers, gather the embers the shards drop — and keep the fire alive. No build step and no network: plain static files, code-drawn art, and a synthesized WebAudio soundtrack.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
